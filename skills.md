# Skills

What I can do, and where I've used it. Each link goes to the project.

## Earth observation and remote sensing

- **Synthetic aperture radar:** P-band SAR from Biomass, HH and VV polarisation, co-polar phase difference, speckle filtering and multilooking. [Salinity from Biomass](projects.html#sea-surface-salinity-from-biomass), [Amazon plume](projects.html#hh-vv-phase-over-the-amazon-plume)
- **Polarimetry:** Pauli decomposition and H/α (Cloude-Pottier) analysis. [Pacific ocean front](projects.html#an-ocean-front-in-the-pacific)
- **InSAR:** ground deformation at volcanoes and peatland monitoring. [Coursework](projects.html#other-coursework)
- **Ocean and water products:** SMOS, SMAP, GLORYS12, OSTIA, ERA5 and Copernicus Marine for validation. [Salinity from Biomass](projects.html#sea-surface-salinity-from-biomass), [Pacific ocean front](projects.html#an-ocean-front-in-the-pacific)
- **Optical and altimetry:** Sentinel-2 for water quality and SWOT for lake levels. [Blessington Lakes](projects.html#blessington-lakes-from-space)
- **Finding and handling data:** ESA MAAP, STAC catalogue searches and large batch downloads. [Mapping the Biomass catalogue](projects.html#mapping-everywhere-biomass-has-looked)

## Programming and data

- **Python:** NumPy, xarray, Matplotlib, Plotly, tifffile and Cartopy, in Jupyter notebooks. Used in almost every project here.
- **Long-running pipelines:** scripts that resume after failures and checkpoint their progress. [Mapping the Biomass catalogue](projects.html#mapping-everywhere-biomass-has-looked)
- **Signal and data analysis:** FFT cross-spectra, curve fitting and calibration. [Pacific ocean front](projects.html#an-ocean-front-in-the-pacific), [Gamma-ray detectors](projects.html#comparing-gamma-ray-detectors)
- **Embedded code:** MicroPython on a Raspberry Pi Pico for a flight payload. [SQRT balloon](projects.html#sqrt-high-altitude-balloon)
- **Orbit modelling:** Python simulations with NASA JPL data, and GMAT. [Launch windows to Jupiter](projects.html#launch-windows-to-jupiter-and-beyond)
- **Writing it up:** LaTeX reports, Git and GitHub. [My code on GitHub](https://github.com/orlaithdoyle/Biomass_ocean)
